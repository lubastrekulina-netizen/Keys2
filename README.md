# Кейс-задача № 2 — Базовый и производный классы (C++)

##  Задание

Написать тестовую программу, которая демонстрирует работу методов
базового и производного классов.

##  Что делает программа

1. Создаёт объекты классов `Dog` и `Cat` (наследники `Animal`).
2. Вызывает методы **базового** класса (`show()`).
3. Вызывает **переопределённые** методы наследников (`sound()`, `kind()`).
4. Вызывает **собственные** методы наследников (`fetch()`, `sleep()`).
5. Демонстрирует **полиморфизм** через указатель на базовый класс.
6. Показывает разницу: без `virtual` вызов через `Animal*` идёт в
   `Animal::sound()`, а не в `Dog::sound()`.
7. Проверяет реальный тип объекта через `dynamic_cast`.

##  Классы

### Базовый класс `Animal`
| Метод | Назначение |
|---|---|
| `Animal(string n)` | конструктор, сохраняет имя |
| `void show()` | выводит «Я животное по имени …» |
| `string sound()` | издает звук (в базовом — `"..."`) |
| `string kind()` | возвращает вид (в базовом — `"Животное"`) |

### Производный класс `Dog : public Animal`
| Метод | Назначение |
|---|---|
| `Dog(string n)` | вызывает `Animal(n)` |
| `string sound()` | `"Гав-гав"` |
| `string kind()` | `"Собака"` |
| `string fetch()` | собственный: «…приносит палку» |

### Производный класс `Cat : public Animal`
| Метод | Назначение |
|---|---|
| `Cat(string n)` | вызывает `Animal(n)` |
| `string sound()` | `"Мяу"` |
| `string kind()` | `"Кошка"` |
| `string sleep()` | собственный: «…спит на подоконнике» |
