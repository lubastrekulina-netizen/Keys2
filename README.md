# Кейс № 2 — Базовый и производный классы (C++)

##  Задание

Написать тестовую программу, которая демонстрирует работу методов
базового и производного классов.

##  Что делает программа

1. Создаёт объекты классов `Dog` и `Cat` (наследники `Animal`).
2. Вызывает методы **базового** класса (`show()`).
3. Вызывает **переопределённые** методы наследников (`sound()`, `kind()`).
4. Вызывает **собственные** методы наследников (`fetch()`, `sleep()`).
5. Демонстрирует **полиморфизм** через указатель на базовый класс.
6. Показывает разницу: без `virtual` вызов через `Animal*` идёт в
   `Animal::sound()`, а не в `Dog::sound()`.
7. Проверяет реальный тип объекта через `dynamic_cast`.
